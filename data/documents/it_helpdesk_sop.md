# IT 헬프데스크 업무 SOP (v3.0)

## 1. 서비스 요청 채널
- 요청은 사내 포털 > IT지원 신청 또는 #it-헬프데스크 채널로 접수한다.
- SLA: 긴급(시스템 다운, 보안 사고) 1시간 내 대응, 일반 요청 24시간 내 대응.

## 2. 비밀번호 초기화
1. 신청인은 본인 확인(ID 카드 또는 부서장 확인 메일)을 받는다.
2. 헬프데스크가 초기화(임시 비밀번호 발급) 후 신청인에게 개별 전달한다.
3. 신청인은 최초 로그인 시 비밀번호를 즉시 변경해야 한다.

## 3. 소프트웨어 설치 요청
- 보안 검토가 필요한 소프트웨어는 IT 보안팀 승인 후 설치한다(라이선스 확인 포함).
- 승인 절차: 요청서 제출 → 보안 검토(영업일 3일) → 승인/반려 → 설치 지원.

## 4. 노트북 반납 절차
1. 사전에 개인 파일 백업(백업 서버 또는 승인된 외부 저장소)을 완료한다.
2. 포털에서 반납 신청 후 IT지원에 기기를 제출한다.
3. IT지원이 초기화(하드디스크 포맷 + OS 재설치)하고 반납 확인서를 발급한다.
4. 분실 시 보안 규정 제5조에 따라 즉시 보고한다.

## 5. 데이터 백업 규칙
- 회사 지급 PC의 업무 문서는 4시간마다 자동으로 백업 서버에 동기화되며, 1년간 보관된다.
- 별도 수동 백업이 필요한 경우 IT지원에 요청한다.

## 6. 보안 패치와 장애 보고
- 보안 패치는 매주 화요일 22시에 적용되며, 재택 PC는 다음 연동 시 반영된다.
- 장애 발생 시 #it-incident 채널에 영향 범위와 복구 시점을 공지한다.
- 개인정보를 포함한 데이터를 헬프데스크에 메신저로 전송하지 않는다(보안 채널 이용).
