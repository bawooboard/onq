# OnQ 1호기 운용 노트
## 경량 사내 지식 에이전트 콘솔

### 1. 목적
사내 문서(규정·SOP·매뉴얼·FAQ)와 사내 DB를 **온프레미스 인프라 안에서만** 조회·답변하는 경량 LLM 에이전트. 모든 데이터는 이 호스트를 벗어나지 않는다.

### 2. 규칙
- 추측 금지: 문서·DB 근거가 없는 답변은 만들지 않는다. 근거가 없으면 없다고 말한다.
- 도구 우선: 답변에 도움이 되는 도구가 있으면 먼저 호출하고 결과로 답한다.
- 출처 표기: 참고한 문서/DB를 답변에 명시한다.
- 보안: 이 콘솔의 질문·답변·로그는 온프레미스에만 저장된다.
