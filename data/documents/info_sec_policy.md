# 한빛전자 정보보안 규정 (v4.2)

## 제1조 목적과 적용 범위
본 규정은 한빛전자(주)의 정보 자산과 업무 데이터를 보호하기 위한 기본 원칙을 정한다. 모든 임직원, 협력업체 상주 인력, 계약직에게 적용된다.

## 제2조 데이터 분류와 외부 반출
회사의 업무 데이터는 중요도에 따라 3단계로 분류한다.
- 1급(대외비): 재무·영업 비밀, 인사 정보, 미공개 제품 사양. 승인 없는 외부 전송 금지.
- 2급(사내용): 내부 규정, 일반 업무 문서. 사내 시스템 내에서만 공유.
- 3급(공개): 마케팅 공개 자료.

**모든 업무 데이터는 원칙적으로 사내 시스템에서만 처리한다.** 외부 클라우드 저장소(구글 드라이브, 드롭박스, 네이버 클라우드 등)에 업무 자료를 업로드하는 것은 금지한다. 자료 반출이 필요한 경우 보안 담당자의 사전 승인을 받아야 한다.

## 제3조 저장매체와 하드웨어 사용
- 이동식 저장매체(USB 메모리, 외장 HDD, CD/DVD)의 업무용 사용은 **금지**한다. 부득이하게 사용해야 하는 경우 보안 담당자 승인과 보안USB 사용 절차를 따른다.
- 개인 소유의 노트북·스마트폰·태블릿을 업무 데이터 처리에 사용할 수 없다. 반드시 회사 지급 기기를 사용한다.
- 회사 지급 노트북·모바일 기기는 본인 확인 후 사용하고, 화면 잠금 시간은 5분 이내로 설정한다.

## 제4조 계정과 비밀번호
- 비밀번호는 **90일마다 변경**해야 하며, 8자 이상으로 영문 대문자·소문자·숫자·특수문자 중 3종 이상을 조합한다.
- 동일 비밀번호 재사용, 생년월일·사번 등 유추 가능한 비밀번호 사용을 금지한다.
- 본인 계정을 타인과 공유할 수 없다. 퇴사·전출 시 계정은 즉시 정지된다.

## 제5조 보안 사고 보고
보안 사고(노트북 분실, 악성 이메일 열람, 의심스러운 접근, 데이터 유출 의심 등)를 인지한 경우 **24시간 이내**에 보안 담당자와 IT 헬프데스크에 보고한다. 보고를 지연하거나 은폐하는 경우 별도 징계 사유가 된다.

## 제6조 재택·외부 접속
- 재택 근무는 회사가 인가한 VPN을 통해서만 회사 시스템에 접속한다.
- 공용 Wi-Fi에서 회사 시스템 접속을 금지하며, 미인가 원격제어 도구(AnyDesk, TeamViewer 등) 사용을 금지한다.
